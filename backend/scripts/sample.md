# Introduction to the Coding Playground

Welcome to Ada's coding playground! This is where you will write, execute, and test your code while interacting with your AI tutor.

## Features

1. **Integrated Environment**: Write HTML, CSS, and JavaScript directly in your browser.
2. **Instant Previews**: See the results of your code immediately as you type.
3. **AI Assistance**: Ask Ada questions about your code, errors, or concepts.

## Basic Syntax

Here is an example of a simple JavaScript function:

```javascript
function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Ada"));
```

## Troubleshooting

If you encounter errors:
- Check your syntax carefully.
- Ensure all brackets and quotes are closed.
- Read the error message in the console, as it often provides clues.
- If you're stuck, ask Ada for help!
